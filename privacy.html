개인정보처리방침

주식회사 오브이제이(OVJ, 이하 「회사」)는 회사 내부 업무용으로 만든 Google API 연동 도구 「OVJ Portfolio Uploader」에서 다루는 정보를 아래와 같이 처리합니다.

1. 이용 범위

이 도구는 회사 대표자 본인의 Google 계정에 연결해 작품 목록 시트 작성, 회사 드라이브 파일 관리, 회사 유튜브 채널 영상 업로드에만 사용합니다. 외부 이용자에게 제공하는 서비스가 아닙니다.

2. 처리하는 정보

  • Google 계정 인증 토큰 — 회사 업무용 컴퓨터에만 저장합니다.
  • 이 도구가 만들거나 연 Google 드라이브·시트 파일, 업로드하는 영상과 그 제목·설명

3. 제3자 제공·판매

Google API로 받은 정보를 제3자에게 제공·판매하지 않으며, 광고나 다른 목적에 쓰지 않습니다. Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.

4. 보관과 삭제

정보는 위 업무에 필요한 동안만 보관합니다. 연결을 끊으려면 Google 계정의 「서드 파티 액세스」에서 권한을 해제하면 되며, 이때 저장된 토큰은 쓸 수 없게 됩니다.
